# Scribo
A secure, browser-based personal notebook built with Flask. Scribo lets users create, edit, and manage multiple notes right from their browser. It includes password protection, note organization, and sleek UI enhancements like dark mode and timestamps. Perfect for anyone who wants privacy, simplicity, and full control over their notes.

# 📝 Scribo — A Flask-based Personal Notebook

Scribo is a lightweight web application that turns your browser into your own private notebook.  
Built with **Flask**, it’s designed for simplicity, privacy, and ease of use.

---

## 🚀 Features

- 🔒 **Password Protection** — Secure your notes with a login page.  
- 🗂️ **Multiple Note Files** — Manage multiple notebooks in one interface.  
- ✏️ **Create, Edit & Update Notes** — Full CRUD functionality for your ideas.  
- 🕒 **Timestamps** — Keep track of when your notes were created or edited.  
- 🌙 **Dark Mode** — Because staring into a white void hurts.  
- 🔍 **Search & Rename** *(coming soon)* — Find and organize your notes effortlessly.  
- 🗑️ **Delete Notes** *(coming soon)* — Goodbye, bad drafts.

---

## 🧠 Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML, CSS, JS
- **Storage:** Local text files / SQLite (depending on setup)
- **Authentication:** Basic password protection via Flask sessions
